# AMCAS_Assignment1
AMCAS Assignment 1 files and results

This repository contains the simulation work for **Assignment 1: "Simulating Memory: Devices to Systems"**.

The first three parts investigate memory from the device and circuit level to the cache-array level:

- **Part A:** 6T SRAM cell simulation using ngspice
- **Part B:** SRAM cache organization and analysis using CACTI 7
- **Part C:** STT-MRAM cache analysis using NVSim

The overall objective is to compare SRAM and STT-MRAM as possible implementations of a **2 MB L2 cache** for an accelerator.
